# Field Notes Content Directory

This directory acts as the public, working digital garden and content repository for Tharun Gajula's AI portfolio. 

## Structure

*   `/notes/`: Concept explanations, build logs, and system designs.
*   `/resources/`: Curated research papers, guides, and technical sources with personal takeaways.
*   `/glossary/`: Plain-language definitions of core AI concepts.

All content in this folder is maintained as static-first markdown files, which are processed directly into the portfolio UI without database dependencies.
