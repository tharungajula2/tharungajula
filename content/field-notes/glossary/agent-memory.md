## Plain definition
Agent memory represents the structured state architectures that allow autonomous agents to persist, retrieve, and update information across multiple steps of an execution loop or over multiple separate user sessions.

## Why it matters
Without structured memory partitions (such as short-term working state, episodic execution logs, and semantic databases), an agent acts as a stateless entity, making it unable to learn from execution errors or adapt to complex tasks.
