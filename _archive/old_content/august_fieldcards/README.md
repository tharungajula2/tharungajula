# 🎴 Field Cards — Standalone Interactive & Reference Notes

Field Cards are self-contained HTML reference documents and interactive simulators covering focused domain concepts, system architectures, regulatory frameworks, and engineering cheat sheets.

> [!NOTE]
> Field Cards are stored as standalone HTML assets in organized domain categories. They can be viewed directly in a browser or accessed on the web application at `/notebook`.
