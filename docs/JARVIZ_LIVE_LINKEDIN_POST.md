## 📝 LinkedIn Post Template

Most developer portfolios are static resumes wrapped in a pretty CSS framework. 

As a builder focused on **Agentic AI** and **Systems Architecture**, I wanted to build something different: an embodied spatial interface you don't just click—you interact with.

Meet **JARVIZ Live** 🤖—an embodied AI cockpit overlay built on top of my personal portfolio.

Instead of clicking buttons, you can:
🖐️ **Wave at it**: Real-time in-browser computer vision (@MediaPipe) tracks your hands. The 3D robot avatar head swivel coordinates track your gestures to trigger page transitions.
🗣️ **Speak to it**: Offline, zero-latency Web Speech recognition maps deterministic commands instantly to navigate the UI.
🧠 **Converse with it**: Open-ended natural language questions automatically route to a serverless Gemini edge streaming API via Server-Sent Events (SSE), streaming and speaking answers back to you in real-time.

### 🛠️ Behind the Scenes (The Tech Stack):
*   **Frontend**: Next.js 16 (App Router + Turbopack) & TypeScript
*   **Computer Vision**: `@mediapipe/tasks-vision` GestureRecognizer
*   **3D Render**: Spline Canvas + pointer-event dispatcher look-at systems
*   **Speech System**: Native Web Speech API (`SpeechRecognition` & `SpeechSynthesis`)
*   **AI Gateway**: Direct secure Server-Sent Events router using `gemini-2.5-flash-lite`

### 🛡️ Privacy & Performance First:
No video feed or microphone recording is ever uploaded. Webcam frames are evaluated entirely locally inside your browser context. And the second you close the cockpit, a comprehensive architectural teardown stops all webcam feeds, speech synthesis buffers, and serverless streams to preserve client battery and processing power.
