## ⏱️ Video/Live Timeline Outline (Total: ~75 Seconds)

### 1. Opening Statement (0:00 - 0:10)
> *"Most personal portfolios are static resumes wrapped in a stylesheet. I wanted to build something different—an embodied interface that lets you wave at it, speak to it, and converse with it. Welcome to JARVIZ Live."*

### 2. Gesture Control Sequence (0:10 - 0:25)
> *"By enabling the camera, we activate a browser-side MediaPipe computer vision stream. The 3D robot avatar instantly tracks my hand coordinates, and we can navigate entirely via spatial gestures."*
*   **Action**: Click **"Enable Camera"** on the consent card. Show hand in frame.
*   **Visual**: 3D robot head swivels to track hand movement seamlessly.
*   **Action**: Perform an **Open Palm** gesture (Wakes system), then **Swipe Right**.
*   **Visual**: Cyan banner flashes `NAVIGATION CONFIRMED → WORK` and the background switches to the Neural projects page.

### 3. Voice Control Sequence (0:25 - 0:40)
> *"If I want to speak instead of gesture, I can activate local voice command parsing. The browser parses exact grammar patterns with zero-latency offline matching."*
*   **Action**: Click the microphone icon to enable **Voice Mode**.
*   **Action**: Say clearly: *"Go home"*.
*   **Visual**: Banner flashes `RETURNING → THESIS`, active viewport indicator updates, and the background shifts back to the core thesis.
*   **Action**: Robot says: *"Returning to core thesis."*

### 4. Non-Deterministic Gemini Query (0:40 - 1:00)
> *"But what happens if I ask an open-ended question that isn't hardcoded? The FSM dynamically forwards natural language to a serverless Gemini Edge SSE stream, displaying real-time plain text fragments before speaking the final answer."*

*   **Visual**: FSM state switches to purple `GEMINI STREAM ACTIVE` pulse, and text streams line-by-line onto the terminal console before being spoken out loud by the browser's premium synthesis engine.

### 5. Architectural Clean Up & Exit (1:00 - 1:15)
> *"When the recruiter exits the cockpit, the architecture runs a complete teardown—killing webcam sensors, microphone tracks, active SpeechSynthesis loops, and live streams to preserve the client's battery and processing power."*
*   **Action**: Click the **"Exit Cockpit"** button (or press `Esc`).
*   **Visual**: Cockpit overlays slide out, camera/mic lights instantly turn off, leaving the portfolio perfectly clean and performant.

2.  **Speak Confidently**: Use natural pauses. Let the text finish streaming before speaking the next line to avoid audio overlaps.
3.  **Checklist Checkoff**: You can check off items inside the Command Manual interactive guide during practice to make sure you didn't miss a beat!
