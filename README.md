## 🚀 Key Features

- **Terminal App Routing**: A unified, terminal browser aesthetic leveraging pure Next.js routes (`/map`, `/profile`, `/contact`) over messy modal popups.
- **The Zettelkasten Digital Garden**: A bidirectional, graph-mapped knowledge base for quantitative finance and ML notes.
- **Native Math Equations**: Advanced physics and corporate finance LaTeX rendering (`$E=mc^2$`) native to the markdown engine via KaTeX, circumventing Next.js Turbopack global compilation roadblocks via custom polyfilling.
- **3D Reactor Core Desktop**: A hardware-accelerated, continuously rotating geometric mesh powered by React Three Fiber operating as a fluid, zero-index background screensaver.
- **Pure Glassmorphism**: Complete removal of flat UI in favor of highly translucent, shadow-inset styling mapping `bg-slate-900/30 backdrop-blur-2xl border-white/10`.

## 🛠 Tech Stack

*   **Framework:** Next.js 16.1.6 (App Router + Turbopack)
*   **Styling:** Tailwind CSS v4
*   **3D Engine:** Three.js + `@react-three/fiber` + `@react-three/drei`
*   **Note Parsing:** `react-markdown` + `remark-math` + `rehype-katex`
*   **Icons:** Lucide React
*   **Font System:** Google Fonts (Inter stringency, Outfit headers, JetBrains Mono tracking)

## ⚡ Deployment & Installation

First, pull the codebase:

```bash
git clone https://github.com/tharungajula2/tharun-os.git
cd tharun-os
```

Install packages and run the development server:

```bash
npm install
npm run dev
```

Navigate to [http://localhost:3000](http://localhost:3000) to boot the OS.
