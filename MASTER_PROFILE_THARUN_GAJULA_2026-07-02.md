## 7. Product Lab Systems

### JARVIZ Live (AI Explorer) — the portfolio itself
- **Status:** Live portfolio system.
- **What it is:** An interactive AI cockpit built into the portfolio — live chat, streaming responses, and guided UI state changes driven by structured prompts.
- **Interview line:** "It demonstrates how structured prompt guidance can translate user queries into deterministic UI state changes."
- **Do not overclaim:** It is a guided, browser-based state machine, not an autonomous distributed agent.
- **Next:** MCP integration and client-side vector lookup.

### Parents Health OS
- **Status:** Live concept prototype. Master reference: `parents-health-os_2026-07-02_master_reference.md`.
- **Public description (synced):** Remote elder-care console for Indian families. Parents check in over WhatsApp — no app to learn — while the family dashboard tracks medications, vitals, and triage, and generates doctor-ready briefs. Local-first by design.
- **What it proves:** Care-workflow architecture (triage states, adherence tracking, escalation logic), privacy-first engineering (local Sandbox Data Vault, DPDP-readiness, consent onboarding), and bounded non-diagnostic AI (the Anaya automation layer).
- **Interview line:** "The parents never touch an app. Anaya runs WhatsApp check-ins, the coordinator dashboard handles meds, vitals, and triage, and the system compiles doctor-ready briefs for consultations."
- **Next:** Live WhatsApp API integration (Anaya moves from simulated to real) and vitals trend alerts.

### Quant OS
- **Status:** Live concept prototype. Master reference: `quant-os_2026-07-02_master_reference.md`.
- **Public description (synced):** Spatial knowledge base for quantitative finance. Markdown notes become an interactive graph with wikilinks, backlinks, KaTeX math, and mastery tracking — plus Vian AI, a terminal chatbot grounded strictly in the knowledge base.
- **What it proves:** Force-directed graph architecture, a full wiki engine (wikilinks, automated backlinking, frontmatter metadata), KaTeX rendering for math-heavy content, gamified progress tracking (OS Sync), and a working RAG assistant with access control.
- **Interview line:** "It turns a folder of markdown notes into a navigable neural map, and Vian AI answers only from that knowledge base — a deliberate hallucination guardrail."
- **Next:** Hybrid vector search for Vian AI and spaced-repetition review.

### Curiosity OS
- **Status:** Concept prototype (V1.0). Master reference: `curiosity-os_2026-07-02_master_reference.md`.
- **Public description (synced):** A digital lab for training thinking skills. Runnable activity playbooks, evidence logging and reflection tools, curated learning paths, and a 3D causal knowledge map explored through Student, Mentor, and Builder lenses.
- **What it proves:** Session-based product design (activities are run, not read — evidence capture, reflection workspace, follow-up planning), curriculum architecture (six learning paths), and WebGL/3D interface engineering (NeuralCore gateway, causal graph navigation).
- **Interview line:** "It treats thinking skills like a gym. You run a playbook, log evidence during the session, then reflect on what worked — and the 3D map shows how concepts causally connect."
- **Next:** Session history across paths and shared classroom sessions.
